# **Transaction Service**

A **Spring Boot Microservice** for managing **authentication service**. It consumes the messages to validate the RFID
cards or
virtual tokens.

## **🚀 Features**

- Consumes the messages and **authentication service to validate the RFID cards or virtual tokens**

---

## **🛠️ Tech Stack**

- **Java 17**
- **Spring Boot 3.x**
- **Kafka 3.X**
- **Maven**

---

## **🔧 Setup & Run**

### **1️⃣ Clone the Repository**

```sh
git clone https://github.com/mritunjayk87/kafka-producer-consumer.git
cd csms-authentication-service
run mvn clean install
```
