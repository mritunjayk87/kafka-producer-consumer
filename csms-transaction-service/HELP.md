# **Transaction Service**

A **Spring Boot Microservice** for managing **transaction service**. It uses rest API to validate the RFID cards or
virtual tokens.
We uses Rest API to validate the RFID cards or virtual tokens. It uses Kafka to send the messages to the Kafka topic.

## **🚀 Features**

- RESTful CRUD APIs for **transactions service to validate the RFID cards or virtual tokens**

---

## **🛠️ Tech Stack**

- **Java 17**
- **Spring Boot 3.x**
- **Kafka 3.X**
- **Maven**

---
